# HK-HorseRacing OAuth

This site provides public information for the Google OAuth client used by the private HK-HorseRacing runtime.

The runtime uses rclone on a user-controlled private VM to read a race-fixture CSV and upload prediction PDFs to the owner's Google Drive. No prediction service, VM endpoint, token, race data, or account data is published here.

Read the [Privacy Policy](privacy.md).
